# Docs

- [`adr/`](adr/) — architecture decision records. Start here for *why*.
- [`architecture/`](architecture/) — current system shape and data flow.
- [`plans/`](plans/) — design documents for a piece of work, written before
  implementation.

Conventions: decisions that are non-trivial get an ADR; a plan describes a
body of work that spans more than one file; architecture docs describe the
system *as it is*.
